# Server (Express + TypeScript + Prisma)

Usage:

1. Copy `.env.example` to `.env` and set DATABASE_URL to your local Docker MySQL (example in `.env.example`).
2. Start the local DB: `docker compose up -d` (from project root).
3. In `server/` run `npm install`.
4. Generate Prisma client: `npx prisma generate`.
5. Run migrations: `npx prisma migrate dev --name init` (requires DB running).
6. Start dev server: `npm run dev`.

Endpoints:

- GET /api/health — basic health check
- POST /api/auth/login — login (dev user: landlord@example.com / password)
- GET /api/tenants — list tenants (protected)
- POST /api/tenants — create tenant (protected)
- GET /api/payments — list payments (protected)
- POST /api/payments — record a payment (protected)
- POST /api/mpesa/stk-push — initiate STK push (protected, sandbox if credentials are set, otherwise simulated)
- POST /api/mpesa/callback — M-Pesa callback receiver (handles Daraja callback payload)

M-Pesa sandbox setup:

1. Register or use Daraja sandbox credentials and set these environment variables in `.env`:
   - MPESA_CONSUMER_KEY
   - MPESA_CONSUMER_SECRET
   - MPESA_SHORTCODE (usually 174379 in sandbox)
   - MPESA_PASSKEY
   - MPESA_CALLBACK_URL (e.g., http://localhost:4000/api/mpesa/callback)
2. When the above are present the server will attempt to call Daraja sandbox endpoints for OAuth and STK Push. Without them, the STK Push endpoint will simulate a checkout response for local testing.

DB setup & seeding (local with Docker Compose or XAMPP):

1. If you're using Docker (optional): Start MySQL: `docker compose up -d` (from project root). The provided `docker-compose.yml` exposes MySQL on 3306.

2. If you're using XAMPP: start **MySQL** from the XAMPP control panel (default host: `localhost`, port: `3306`).

3. Copy `.env.example` to `.env` and set `DATABASE_URL` to point to your MySQL instance, for example:
   - Docker example: `mysql://root:password@localhost:3306/my_hostel_app`
   - XAMPP example (your values): `mysql://root:MyServer@localhost:3306/my_hostel_app`

4. Run the automated db setup from `server/` which waits for the DB and runs Prisma commands:

   ```bash
   cd server
   npm install
   npm run db:setup
   ```

   The `db:setup` script runs a small cross-platform wait script, then `prisma generate`, `prisma migrate`, and `prisma:seed`.

5. Alternatively, you can run the Prisma steps manually:
   - `npx prisma generate`
   - `npx prisma migrate dev --name init`
   - `npm run prisma:seed`

6. Start both server and client together from project root:

   - Quick start without waiting for DB: `npm run dev:all`
   - Start and wait for DB first (recommended when using XAMPP): `npm run dev:with-db`

Notes:
- If your MySQL uses a different root password, update `server/.env` accordingly.
- On Windows, run the commands from PowerShell or a terminal with Node/npm available.
